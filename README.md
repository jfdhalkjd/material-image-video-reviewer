# 朋友圈图片审核插件（阶段 1：只读原型）

## 当前状态

已按你的目标 Base 做了只读原型：读取当前活动表，展示 `朋友圈配图-AI` 中逗号/换行分隔的 JPG URL，并展示品类、追评文案和 recordId。当前版本已包含本地交互草稿与并发校验代码，但首次安装验证前不建议对正式表写入；下一步应先接入测试表，验证 SDK 版本和字段取值形态。

## 已确认的目标表

- 表：`（图文）朋友圈内容生产表`
- 必需字段：`朋友圈配图-AI`（文本）
- 当前视图读取到 8 条记录，7 条有图片 URL，1 条为空
- `编号` 当前为空，插件暂以 `recordId` 作为行标识

## 本地运行

```bash
npm install
npm run dev
```

普通浏览器只能做界面预览；要读取真实 Base，必须在飞书多维表格插件容器中运行。

## 下一步测试顺序

1. 先把 SDK 版本锁定并在飞书插件开发环境构建。
2. 用测试表只读打开，验证 1/2/3 张图、逗号和换行分隔、失效 URL。
3. 再打开写回开关，验证删除第一/中间/最后一张、删光、并发变化、重复点击、撤销。
4. 最后才绑定正式表。

## 重要限制

官方文档中的活动视图能力仍标注为测试能力，因此实现必须保留整表读取回退，不使用 DOM 模拟飞书页面。图片 URL 本身必须允许飞书插件 iframe 加载；如果源站禁止跨域/防盗链，插件只能提供“打开原图”，无法强行解决。
